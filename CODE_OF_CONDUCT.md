# Code of Conduct

TTPrism adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be respectful and constructive, assume good faith, and keep
discussions about the work, not the person. Harassment, personal attacks and publishing others'
private information are not tolerated.

For a security tool there is one more expectation: do not use project spaces (issues, pull
requests, discussions) to share non-public threat intelligence, live malware or anyone's personal
data.

## Reporting

Report unacceptable behaviour privately to the maintainer,
[@yuchen-0321](https://github.com/yuchen-0321). Until a dedicated contact address is listed here,
open a public issue titled "Conduct contact request" **without any details**, and the maintainer
will arrange a private channel. Reports are handled confidentially.

## Enforcement

The maintainer will review every report and may respond with a warning, temporary ban or permanent
ban, following the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
